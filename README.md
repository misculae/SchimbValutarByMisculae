# Schimb Valutar by Misculae

Aplicație Android pentru compararea cursurilor USD/RON, ofertelor băncilor și caselor de schimb din București, plus cursurile oficiale BNR.

## Funcții planificate
- Calculator USD → RON cu comisioane configurabile.
- Comparație netă între retragere numerar BT, transfer Revolut, bănci și case de schimb.
- Cursuri BNR (EUR, USD și alte valute), cu data publicării.
- Sursa și ora ultimei actualizări pentru fiecare ofertă.
- Rezultate sortate după suma netă în RON.

## Valori inițiale configurabile
- Retragere numerar BT: 0,9% din suma retrasă în USD.
- Transfer Revolut: 18 USD taxă fixă (valoare estimată introdusă de utilizator).
- Suma inițială: 5.000 USD.

Proiect Android cu Kotlin și Jetpack Compose.
